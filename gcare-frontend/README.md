# GCare Council Website - Frontend

## 1. Project Overview

The GCare Council Website is a web-based platform developed to manage and provide information about GCare Council services, training programmes, courses, student admissions, internships, affiliations, institutional activities, and LMS-related services.

This repository contains the frontend implementation of the GCare Council website.

---

## 2. Project Name

**GCare Council Website**

---

## 3. Frontend Technology Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
- Responsive Web Design

---

## 4. Backend Technology Stack

The frontend communicates with a separate backend application developed using:

- Node.js
- Express.js
- MySQL
- REST API
- Multer for file uploads
- Google Drive integration for document storage
- Railway for backend deployment
